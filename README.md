# Flight-price-prediction

An end-to-end Machine Learning project that predicts flight ticket prices based on operational, temporal, and geographic features. Built using Python, Pandas, Scikit-Learn, and XGBoost.

---
Project Overview
Flight ticket prices fluctuate dynamically due to multiple factors like booking time, total stops, airlines, and route duration. This project builds a robust regression pipeline to clean historical flight data, engineer relevant temporal and categorical features, and predict ticket fares accurately.

Best Model Performance (XGBoost):
  * **Train $R^2$ (Log Scale):** 0.8841
  * **Test $R^2$ (Log Scale):** 0.8578
  * **Real-world $R^2$ Score:** 0.8190 
  * **Mean Absolute Error (MAE):** ₹1,330.69
